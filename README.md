# Hospital Emergency Room Dashboard

## Project Overview
This project is an interactive Hospital Emergency Room Dashboard developed using Microsoft Excel to analyze and visualize hospital patient data.

## Key Performance Indicators (KPIs)
- Total Number of Patients
- Average Waiting Time
- Patient Satisfaction Score

## Dashboard Insights
- Patient Attendance Status
- Gender-wise Patient Distribution
- Age Group Analysis
- Department-wise Patient Distribution
- Monthly Patient Analysis

## Tools & Skills Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Dashboard Development

## Project Objective
The objective of this project is to transform hospital data into meaningful insights and present them through an interactive dashboard to support better decision-making.
